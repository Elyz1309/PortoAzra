# Farabi Akil Azra — Creative Portfolio

Website portofolio statis dibuat dengan HTML dan CSS, siap dipublikasikan melalui GitHub Pages.

## Struktur

- `index.html` — konten dan struktur halaman.
- `style.css` — tampilan, layout responsif, dan warna.
- `assets/` — gambar karya yang diekstrak dari PDF portofolio.

## Menjalankan secara lokal

Buka `index.html` di browser. Tidak memerlukan Node.js, framework, atau proses build.

## Deploy ke GitHub Pages

1. Buat repository baru di GitHub, misalnya `farabi-portfolio`.
2. Upload seluruh isi folder ini (pastikan `index.html`, `style.css`, dan folder `assets` berada di root repository).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses deployment selesai. Website akan tersedia pada alamat `https://USERNAME.github.io/farabi-portfolio/`.

Untuk domain utama `USERNAME.github.io`, nama repository harus `USERNAME.github.io`.

## Catatan

- Ubah alamat email, tautan sosial, dan konten pada `index.html` jika diperlukan.
- Tautan LinkedIn pada template diarahkan ke halaman utama LinkedIn karena URL profil pada PDF tidak terbaca dengan format yang valid. Ganti dengan URL profil LinkedIn yang benar.
- Font menggunakan Google Fonts; jika tidak tersedia, browser akan memakai font sans-serif lokal.
